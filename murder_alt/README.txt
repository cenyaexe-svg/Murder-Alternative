MURDER ALT - режим для Garry's Mod (альтернатива Homicide)

УСТАНОВКА
1. Распакуйте архив так, чтобы папка "murder_alt" лежала в:
   garrysmod/gamemodes/murder_alt
   (должны быть murder_alt/murder_alt.txt и murder_alt/gamemode/init.lua)
2. Выберите геймод "Murder Alt" в меню игры, либо в консоли:
   gamemode murder_alt
   (для сервера: +gamemode murder_alt)

ПРАВИЛА
- Минимум 2 игрока. Роли выдаются случайно: 1 трейтор на каждые 8 игроков (мин. 1).
- В начале раунда 5 секунд показывается роль ("Вы невиновный" / "Вы трейтор").
- Невиновные: руки (ma_hands из аддона MA Hands; если его нет - weapon_hands, затем weapon_fists).
- Трейторы: weapon_hands, arc9_cod2019_me_knife, arc9_cod2019_pi_357,
  arc9_cod2019_nade_c4, arc9_cod2019_nade_molotov.
- Все трейторы мертвы -> "Победа Невиновных"; все невиновные мертвы -> "Победа Трейторов".
  Затем автоматически начинается новый раунд.
- Одиночная игра (без сервера): бесконечный раунд, игрок всегда невиновный (weapon_hands).
  После смерти возрождается по клику, трейторов и победных экранов нет.
- Q (удерживать) = колесо действий (Drop Weapon; weapon_hands выбросить нельзя), отпустить Q = выбрать.
  Пока зажат Q, в левом верхнем углу показывается роль. F1 = spawn menu, C = обычное контекстное меню.
- Сверху по центру: в одиночке "Одиночная игра - Сандбокс", в мультиплеере "Хомисайд - ММ:СС" (время раунда).
- HUD режима: только экран роли, экран победы и роль в Q-меню (здоровья и патронов нет - используйте свой HUD).

НАСТРОЙКИ: gamemode/shared.lua (время, мин. игроков, скорость, число трейторов).
Нужны аддоны с оружием: weapon_hands и ARC9 COD2019. Если weapon_hands нет,
выдаётся стандартный weapon_fists.

ЗВУК НАЧАЛА РАУНДА
- Файл: content/sound/murder_alt/round_start.mp3 (играется в начале каждого раунда).
- Клиентские команды: ma_round_sound 0 (выключить), ma_round_sound_volume 0.5 (громкость 0-1).
- Чтобы заменить звук, положите свой mp3 под тем же именем.
- На выделенном сервере для скачивания клиентами нужен FastDL или Workshop-аддон с этим файлом.
